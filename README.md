# Automated Log Analyzer

## Project Description

This graduate research project will develop a Python-based tool that analyzes authorized Linux authentication logs. The tool will look for suspicious login activity, such as repeated failed login attempts and unusual authentication patterns.

The project combines cybersecurity, digital forensics, Python programming, and data analysis.

## Project Goals

The goals of this project are to:

- Research cybersecurity log management and log analysis.
- Create a Python program that reads authentication logs.
- Identify suspicious login activity.
- Organize events by time, username, and source address.
- Assign a severity level to suspicious events.
- Create a report of the findings.
- Test the program using safe sample data.
- Identify the program's strengths and limitations.

## Planned Features

The analyzer may:

- Read Linux authentication log files.
- Identify failed and successful login attempts.
- Detect repeated failed login attempts.
- Detect successful logins after multiple failures.
- Identify invalid usernames.
- Group related events by time and source address.
- Assign low, medium, or high severity.
- Export results to a CSV or text report.

## Research Process

The project will follow these steps:

1. Review research about cybersecurity log management.
2. Select and document the log format.
3. Create or obtain safe sample data.
4. Build the log parser.
5. Add detection rules.
6. Create reports.
7. Test the analyzer.
8. Review the results.
9. Revise the project based on feedback.
10. Complete the final report and presentation.

## Evaluation

The analyzer will be evaluated based on:

- How accurately it identifies suspicious events.
- The number of false positives.
- The number of missed events.
- How quickly it processes the logs.
- Whether the reports are clear and useful.
